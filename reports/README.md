# Reports

**Start with [00-final-report.md](00-final-report.md).** It covers the whole project: the final system,
the results, the technical analysis, and the figures. The reports below hold the details of each
experiment, in the order they were run. Every number in them traces back to a run in `runs/` or to
a table in `studies/`.

## Experiment register

| id | question | data | result | report |
|---|---|---|---|---|
| P2 | Is the evaluation code correct? (Gate G2) | synthetic fixtures | Random, perfect and inverted controls hit their analytic values; the 1% false-alarm target is unattainable with small calibration sets | [P2](01-evaluation-apparatus.md) |
| P3 | First numbers on real data | VisA, 3 development categories | Superseded by E00–E04 (protocol v1 defects F01–F04); split audit and licence resolution still stand | [P3](02-first-visa-runs-protocol-v1.md) |
| A4 | Are there near-duplicates across splits? (leakage rule L6) | VisA, all 12; AD 2; MPDD | No train/test leak: test images are no closer to training than training images are to each other | [A4](03-near-duplicate-audit.md) |
| E00–E04 | Which model, resolution and bank? | VisA, 3 development categories | Resolution is the largest effect (320 → 640 px: +0.03 to +0.25 AUROC); a fixed 10k bank costs nothing | [E00–E04](04-visa-development.md) |
| E08 | How robust is the frozen recipe to optical change? | VisA development | The ranking outlives the operating point; input guards refuse every breaking corruption | [E08](05-robustness.md) |

| E8 | Does the screen replicate over 3 seeds? (Gate E) | VisA development | `layer2` at 960 px: `macaroni2` 0.887 → 0.979; candidate v2 | [E8](08-gate-e-followup.md) |

## Data layout

| path | content |
|---|---|
| `runs/<run id>/` | One directory per run: fully resolved spec, result, provenance (git SHA, implementation id, config hash) |
| `results_registry.csv` | All runs in one table, regenerated by `inspector results` |
| `studies/<study>/` | Tables written by the study scripts (`scripts/README.md`) |
| `studies/ad2-server/` | Server results (`server_means.csv`), published references, the proxies |
| `studies/s1-submission/` | The two submissions: recipe, per-category thresholds, archive SHA-256, checker result |
